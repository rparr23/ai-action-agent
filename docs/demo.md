# 90-second recruiter demo

**0:00–0:12 — Problem.** "AI agents become valuable when they can take action, but that creates risk. This project keeps action authorization outside the model."

**0:12–0:30 — Run research.** Submit: _Research enterprise AI governance risks and draft an email to leadership._ Show the visible six-step plan.

**0:30–0:46 — Inspect evidence.** Show the cited NIST, OECD, and EU sources and the execution trace.

**0:46–1:03 — Approval boundary.** Show the exact recipient, subject, body, risk level, and fingerprint-bound approval. Explain that nothing has been sent.

**1:03–1:17 — Reject.** Reject the first action and show `rejected` in the trace. Explain that rejected actions cannot execute.

**1:17–1:26 — Approve safely.** Run another task, approve it, and show the mock receipt with `external_effect: false`.

**1:26–1:30 — Close.** "The repository demonstrates tool orchestration, auditability, idempotency, safe web research, and human control for real-stakes automation."
